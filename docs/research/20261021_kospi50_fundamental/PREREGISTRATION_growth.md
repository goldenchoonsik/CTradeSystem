# 코스피 상위 50 · 성장 지표 — 사전 고정 (2026-10-21, 결과 보기 전)

PREREGISTRATION.md 와 같은 틀(그때의 상위 50, 상위 10 동일가중 매달 교체, 다음 거래일 종가, 왕복 0.45%, 가격수익, 기준 = 시총가중·동일가중 50).
기간: 2017-09 ~ 2023-12 / ~ 2026-08 (분기 YoY 두 번이 필요해 시작이 늦음 — 기준도 같은 기간으로 다시 계산).

- 분기 매출 = 누적 차분(1분기=누적, 4분기=연간−3분기 누적), 매출 없는 금융사는 제외. 그날까지 접수된 최근 분기 기준.
- G1 매출 성장 = 최근 분기 매출 / 전년 같은 분기 − 1 (전년 ≤ 0 제외)
- G2 매출 가속 = G1(최근 분기) − G1(직전 분기)
- G3 성장 대비 PER = G1 순위와 E/P 순위의 평균 (둘 다 있어야)
- G4 3개월 가격 모멘텀(테마 대리) = 신호일 종가 / 63거래일 전 − 1
- 판정: 기존과 동일(두 기간 모두 > 동일가중·> 시총가중, 대 동일가중 월 t ≥ 2.0, 상위 > 하위).
