# 판독 엔진 보충 사전등록 D — 업종 판독 '수요 충격만'(R5-D) 전진 확인 (2026-10-22 고정)

## 왜 따로 등록하나

본 사전등록(PREREGISTRATION_reading_engine.md, sha 49537387…)의 R5 업종 점수는 z(수요 충격 D) + z(미국 점유 C)였다. 2008-01~2026-03 재현에서
성분을 나눠 보니 수요 충격만의 IC 가 +0.157(t 3.5, ~2016 +0.185 · 2017~ +0.130)로 합성(+0.102, t 2.3)보다 좋고, 미국 점유 성분은 0~역효과(~2016 −0.175)였다.
**이 '수요 충격만' 변형은 결과를 보고 고른 것(사후 선택)이다.** 그래서 과거 재현 수치는 판정에 쓰지 않고, 오늘 이후 쌓이는 판독만으로 판정한다.

## 정의 (reading.py 에 고정, sha256 bde349d61be9e56a5203765955eeb2ee47ee38eacfeb7cdfc04a684798e6fa18)

- 점수 `score_D` = 그 달 7개 업종 간 z(D_s). D_s 의 정의·대응표·시점 규칙은 본 사전등록 R5 와 같다(변경 없음).
- 판독 `reading_D`: > 0 우호, < 0 비우호. 합성 점수(사전등록 원안)는 그대로 유지해 나란히 기록한다.
- **전진 기록**: 매달 '시스템 판독' 단계가 돌 때 `FORWARD_FROM = 2026-10-31` 이후 판독(합성·수요만 점수, 수요 판독, 총수출)을
  `DataVault/staging/global_macro/reading/forward_log.jsonl` 에 처음 생성된 그대로 덧붙인다(append-only, 이미 있는 달은 재계산 값으로 덮지 않음).
  판정은 이 기록만 쓴다 — 자료 개정·코드 변경이 과거 판독을 바꿔도 기록은 안 바뀐다.
- 채점: 본 사전등록 R5 와 같음(업종 6개월 수익 − 코스피, 업종 간 순위상관 IC, 상위 2 − 하위 2 차, 우호/비우호 적중). 첫 채점 가능 월 2027-05(2026-10 판독의 6개월 뒤 종가).

## 판정 규칙 (미리 고정)

| 채점 가능한 달 | 상태 |
|---|---|
| 0 | 대기 |
| 1~23 | 확인 중 n/24 (판정 없음) |
| 24 (1차) | 전진 IC_D ≤ 0 → **기각** · IC_D > 0 이고 상위2−하위2 > 0 이고 IC_D ≥ 합성 IC → **확정**(R5 의 운영 점수를 수요 충격만으로 교체) · 그 외 → 보류 |
| 36 (최종, 보류였을 때) | IC_D > 0 이고 상위2−하위2 > 0 → 확정, 아니면 기각 |

- t값은 표시만 한다(24개월·6개월 지평은 독립 표본 4개 수준이라 t 문턱은 쓰지 않음, 2026-10-21 '판단 vs 유의성' 원칙).
- 확정 전까지 운영 판독(화면 '합성 판독')은 사전등록 원안을 따른다. 수요 충격만 판독은 '전진 확인 중' 꼬리표로만 나란히 보여 준다.
- 이 문서와 reading.py 의 상수(FORWARD_FROM, FORWARD_MIN_MONTHS=24, FORWARD_MAX_MONTHS=36)는 판정 전까지 바꾸지 않는다.
