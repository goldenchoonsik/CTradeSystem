# 판독 엔진 보충 사전등록 H — 판독의 지평 곡선(국소투영) (2026-10-22 고정)

## 왜

목표는 "현재 파악 + 3~12개월 예측 확률↑"인데, 수요 판독(R2)·업종 판독(R5)은 6개월 한 지평만 검정했다. 판독의 정보가 **어느 지평에, 언제까지** 남아 있는지를
1~12개월 반응 곡선(국소투영: 지평마다 같은 판독으로 누적 결과를 채점)으로 재서, 화면의 '유효 지평' 표시와 메모 일지의 기본 기간을 정한다.
**이 결과로 운영 채점 지평(6개월)·전진 트랙 D·CE 의 정의는 바꾸지 않는다**(사후 선택 방지). 바꾸려면 새 전진 트랙으로 등록한다.

## 정의 (reading_horizon.py 에 고정)

- 판독 재현: `reading_eval.run_engine` — 2008-01 부터 매달 그 시점 자료만으로 `read_at(t)`. 시점 규칙·대응표(관계 원장 a4e93d6d…)는 본 사전등록(49537387…)과 같다.
- 지평 h ∈ {1, 2, …, 12}(월). 구간: 전체 / 전반 ~2016-12 / 후반 2017~ (본 사전등록과 같은 분할).
- **R2 수요 곡선**: 판독 t 의 예측 Δ(`delta`, 기준 L = t−1 월), 활성 연결(강함·약함)만. 누적 결과 act_h = y_g[t+h] − y_g[L] (y = 3개월 합 수출 로그 전년비).
  - hit_h = sign(Δ) == sign(act_h). 기준선 mr_h = sign(최근 5년 평균 − y_L) == sign(act_h) (본 사전등록의 평균 회귀 기준선, 가장 강한 기준선).
  - 월별로 상대국 평균 → 월 시계열. 보고: hit_h 평균, mr_h 평균, 차이 diff_h = hit_h − mr_h 의 평균과 Newey–West(지연 h) t.
  - 한국 총수출(R3)은 같은 식으로 따로.
- **R5 업종 곡선**: out_h = log(업종[t+h]/업종[t]) − log(코스피[t+h]/코스피[t]). 월별 업종 간 스피어만 IC_h(≥5 업종), 평균과 NW(지연 h) t. spread_h = 상위 2 − 하위 2 업종 out_h 평균.
  - 점수: **합성(score, 본 사전등록 원안) = 주 판정**, 수요 충격만(score_D) = 보충(전진 트랙 D 의 참고, 판정 아님).
  - 기술 보충(판정 아님): 한계 IC — out 을 t+h−1 → t+h 한 달 구간으로 바꿔 정보가 **어느 달에** 반영되는지.

## 판정 규칙 (미리 고정)

- 지평 h 가 '통과' = 전체 구간에서 (R5) IC_h > 0 이고 t_h ≥ 2 / (R2) diff_h > 0 이고 t_h ≥ 2.
- **유효 지평 구간** = 통과한 h 가 **2개 이상 연속**인 가장 긴 구간(단일 지평 통과는 잡음으로 본다). 전반·후반 부호가 같아야 한다(한쪽이 반대면 '불안정' 꼬리표).
- 결과 범주(판독별):
  - (a) 유효 구간이 3~12 와 겹침 → **목표 지평 정합**. 화면 곡선에 구간 표시, 메모 일지 기본 기간 = 구간 안 IC(또는 diff) 최고 지평 h*.
  - (b) 유효 구간이 1~2 뿐 → **단기 정보** — 판독은 현재 파악용, 화면 지평 라벨에 경고.
  - (c) 없음 → **지평 정보 없음** — 곡선은 표시, 판정 없음.
- 다중검정: 12지평 × 판독 2 × 점수 2 = 48 비교. t ≥ 2 + 연속성 + 전후반 부호 일치로 방어하고, 통과 여부와 무관하게 전부 보고한다.
- 지평이 길수록 겹침(중복 표본)이 커져 유효 표본이 줄어든다 — t 는 NW 로 보정하되, 12개월 지평은 2008~ 자료에서 독립 표본 약 18개 수준임을 명시한다.
