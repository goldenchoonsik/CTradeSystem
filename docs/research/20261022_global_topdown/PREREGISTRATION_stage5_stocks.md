# 5단계 사전등록 — 종목 단계 L3: 업종 판독이 종목으로 내려가나 (2026-10-22, 종목 업종코드 수집 중·결과 보기 전 고정)

동기: 업종 판독(R5, 실전 후보)과 수요 충격만(R5-D, 전진 확인 중)이 있다. 실제 매매는 종목이므로 "우호 업종 안에서 어떤 종목이 그 판독의 몫을 더 받나"를 본다.
원래 뜻은 '수출 노출 큰 종목'이었으나 **회사별 수출 비중의 구조화 원천이 없다**(DART 재무 API 에 없음, 사업보고서 본문뿐) → 대리 변수로 **업종 베타**(업종 지수 움직임에 대한 종목 민감도)를 쓴다. 한계로 명시.
코드: `shared/data_library/global_macro/stocks.py` (sha256 c49379fbf47d968c264bfac20e8a200262574ddc55043b4cb0e73d5e9df90f4a), 업종 대응 `kr_ksic.py` (9a93462ed8b0b21be2b9512e4b5fd680aeb6b5cace26142cf699508f0ecd261e) — DART 기업개황 KSIC 2자리 → kr_industry.SECTORS 의 KSIC 열로 코스피 업종.

## 대상·시점

- 종목: 현재 상장 보통주(스팩·우선주 제외) 중 KSIC 가 판독 7업종(화학·제약·금속·기계·전기전자·의료정밀·운송장비)에 대응되는 종목, 코스피·코스닥 모두. **생존 편향**: 상폐사 제외·분류는 오늘 기준(이력 없음) — 결과는 그만큼 낙관.
- 기간: 월말 2013-03~(가격 자료 2013-01~, 베타 24개월 최소 → 실질 2015-01~; 전반 ~2016-12 / 후반 2017-01~ 보고. 전반이 짧으므로 후반이 주 구간).
- 필터(그 시점): 월말 시총 ≥ 500억, 20일 평균 거래대금 ≥ 5억(kr_equity gold_1d, 월말 행).
- 업종 베타 β_i(t): 최근 36개월(최소 24) 종목 월 로그수익(코스피 초과) ~ 업종 지수 월 로그수익(코스피 초과) 기울기, t 까지 자료만.
- 업종 점수: 판독 엔진 이력(reading history)의 합성 점수 score(사전등록 원안)가 주, 수요 충격만 score_D 는 참고.

## 가설·판정 (지평 6개월, 종목 6개월 로그수익)

| # | 내용 | 채점 | 판정 |
|---|---|---|---|
| S1 | 업종 판독 → 종목: 종목 초과수익(코스피 대비) vs 그 종목 업종의 score | 월별 종목 풀 순위상관 IC, NW(6) t; 우호 업종 종목 − 비우호 업종 종목 평균 차 | R5 규칙: IC>0 두 반기 & 전체 t≥2 → 실전 후보 / 두 반기 양 → 작게 실험 / 아니면 버림 |
| S2 | 업종 안 전이 강도: 종목 초과수익(**업종 지수** 대비) vs score × β_i | 월별, 업종 내 평균 제거 후 풀 순위상관 IC; 보조: 우호 업종에서 β 상위 1/3 − 하위 1/3 6개월 차, 비우호 업종에서 같은 차(부호 반대 기대) | 같은 R5 규칙 |
| S3 | S1·S2 를 score_D 로 반복(참고, 판정 없음) | 같음 | 표시만 |

- 기본 확률: 종목이 코스피(S1)·업종 지수(S2)를 이긴 비율을 나란히.
- 조치(미리): S2 실전 후보/작게 실험 → 화면 '종목 후보' 카드에 우호 업종 × 고베타(필터 통과) 목록을 '판독 전이' 꼬리표로; S2 버림 → 같은 카드를 '현재 파악(업종 구성·베타)'로만 표시하고 추천 문구 없이. S1 은 업종 판독이 종목에 닿는지의 확인이며 운영 변경 없음.
- 수출 노출 원천이 생기면(사업보고서 수출/내수 매출 파싱 등) β 대신 그 변수로 S2 를 새 사전등록으로 재시험.
