# 4단계(무역) 사전등록 — 수출 가중 상대국 경기 → 한국·대만 주식 (2026-10-22)

동기: 3단계에서 중국 선행지수는 코스피를 앞섰고 G7 은 못 앞섰다 — 무역 구조(한국의 실제 고객)와 맞는 결과. 그래서 "한국이 실제로 파는 나라들의 경기를 수출 비중으로 가중한 합성 선행지수"가 더 나은 단서인지 본다.
주의: 이 가설은 3단계 한국 결과를 본 뒤 나왔다 → 한국 확인 구간(2010~)은 독립 시험이 아님. **대만(수출 구조가 한국과 비슷, 결과를 보지 않음)이 진짜 확인 시험.**
대응표·원천: `shared/data_library/global_macro/trade.py` PARTNERS(이 문서와 같은 시각 고정). 데이터 수집·형식 확인만 끝난 상태에서 고정.

## 정의

- 상대국 경기 변화: 각 상대국 OECD 선행지수의 6개월 변화(발표 시차 20일, 한국 월말 t 에 공개된 값). 홍콩은 중국 선행지수. 선행지수 없는 상대국(베트남·대만·싱가포르·말레이시아·태국·필리핀·네덜란드·폴란드·러시아·중동)은 합성에서 빠지고 남은 가중치를 합 1 로 다시 맞춤.
- **가중치 g(총수출)**: 한국 → ECOS 상대국별 수출, t 가 속한 해의 **전년** 1~12월 합 비중(1월 말이면 전년 12월분까지 공개됨 = 실시간). 대만 → TiVA 총수출(EXGR) 상대국 비중, 전년(2023년 이후는 2022, 1996년 이전은 1995).
- **가중치 v(부가가치)**: TiVA '해외 최종수요에 담긴 국내 부가가치(FFD_DVA)' 상대국 비중, 전년(같은 경계 처리). TiVA 는 사후 공표라 엄밀한 실시간은 아님(구조가 느리게 변한다는 가정 — 한계로 보고).
- 합성 신호 wCLI(t) = Σ 가중치 × 상대국 선행지수 6개월 변화.

## 가설 (전부 예측 부호 +, 주 지평 6개월)

| # | 신호 → 대상 | 구간·판정 |
|---|---|---|
| T1g | 한국 총수출 가중 wCLI → 코스피 6개월 콜금리 초과 | 개발 ~2009-06 / 확인 2010-01~2026-02, 2단계 규칙 |
| T1v | 한국 부가가치 가중 wCLI → 코스피 | 같음 |
| T2g | 대만 총수출 가중 wCLI → 대만 가권지수 6개월 로그수익 | **이식 시험**: 1998-01~2026-02 전 기간(반기 ~2009-06 / 2010~ 보고), 3단계 K 규칙 |
| T2v | 대만 부가가치 가중 wCLI → 대만 | 같음 |
| T3 | 한국 총수출 가중 wCLI → 수출 업종 바구니(전기전자·운송장비·화학·금속·기계) − 내수 업종 바구니(유통·통신·전기가스·음식료·건설, 동일가중) 6개월 상대 수익 | 개발/확인, 2단계 규칙 |

비교용 보고(판정 없음): 같은 대상에 대한 중국 선행지수 단독, G7 선행지수.

## 판정 규칙

- 2단계 규칙: 개발 예측 부호 & |t| ≥ 2, 확인 같은 부호 & 효과 ≥ 개발 1/2 = 실전 후보 / 두 구간 같은 부호 = 작게 실험 / 반대 = 버림.
- 이식(K) 규칙: 전 기간 예측 부호 & |t| ≥ 2 & 두 반기 같은 부호 = 실전 후보 / 전 기간 예측 부호 = 작게 실험 / 반대 = 버림.
- 통계: 표준화 신호 기울기·Newey–West(6) t, 유리/불리(표준화 기간 중앙값 기준) 시 상승 확률.

## 기술 지도(판정 없음, 화면 '실물 경로')

노출(총수출 vs 부가가치 비중, 1995~2022 + ECOS 총수출 ~2026), 민감도(상대국 선행지수 6개월 변화 → 그 나라로의 한국 수출 전년비, 0~12개월 선후 중 최대 상관·탄력성), 영향력 지수(부가가치 비중 × 탄력성, 합 100).
