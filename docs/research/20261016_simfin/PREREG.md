# SimFin 재무 팩터 시험 — 사전 등록 (2026-10-16, 결과 확인 전)

## 목적
SEC 공시 파싱 대신 SimFin 표준화 재무로 "재무 신호가 이후 수익률을 예측하는가"를 싸게 판정한다. 무료 플랜 표본(2019-10~, 수집된 일부 회사)에서 효과가 없으면 과금 확대는 정당화되지 않고, 효과가 있으면 확대 근거가 된다.

## 표본 (수집 순서로 정해진 일부 — 무작위 아님)
- 재무·주가 파일이 모두 있고 시총·가격이 유효한 회사. 사후 선별 금지.
- 분석 전 표본의 섹터·시총 분포를 먼저 보고한다(편향 확인).

## 시점 규칙 (미래참조 금지)
- 월말 t 에서 `Publish Date + 1일 <= t` 인 최신 분기 값만 사용. Publish Date 없으면 Report Date + 90일.
- 알려진 한계: SimFin 값은 정정(Restated) 반영본일 수 있어 완전한 point-in-time 이 아니다 → 결과 해석에 명시.
- 시총 = t 일 종가 × 발행주식수. 시총 하위(예: 1억 달러 미만)와 주가 $1 미만 제외.

## 신호 5개 (고정, 추가 금지)
1. 이익수익률 = TTM 순이익 / 시총
2. FCF 수익률 = TTM (영업현금흐름 − 설비투자) / 시총
3. 총이익/자산 (gross profitability)
4. 매출 성장 = TTM 매출 YoY
5. 자산 성장 = 총자산 YoY (낮을수록 좋음 → 부호 반전)

## 시험
- 월말마다 신호로 5분위, 다음 1개월 수정종가 수익률. 상위−하위 스프레드 시계열.
- 상폐 등으로 다음 달 가격이 없으면 마지막 가격까지 수익률, 이후 0(보수적 아님: 상폐 손실은 −100% 대신 마지막 가격 기준 → 한계로 명시).

## 합격 기준 (전부 충족해야 "유망")
- 5개 신호 다중검정 보정: 월 스프레드 평균 t >= 2.5 (Newey-West 3 lag).
- 최고 연도 한 해를 빼도 평균 > 0.
- 왕복 비용 0.2%(월 회전율 가정 상위 분위 50%)를 빼도 평균 > 0.
- 하나라도 미달이면 해당 신호는 불합격. 재시험·기준 완화 금지.

## 판정 후
- 합격 신호 있음 → 유료 확대(전 종목·장기)로 같은 규칙 재시험.
- 없음 → SimFin 확대 중단, 결과를 메모리에 기록.
