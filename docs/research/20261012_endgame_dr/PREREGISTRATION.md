## D1 — 선물·옵션 만기일 (069500 일봉 24년)

- 구간(4): a 만기일 오버나잇(만기일 종가 → 다음 거래일 시가), b 만기일 장중(시가 → 종가), c 만기 다음날 장중(시가 → 종가), d 만기 주간(만기 5거래일 전 종가 → 만기일 종가)
- 대상(2): 분기 만기만 / 월 만기 전부 → 시험 8개
- **방향은 발견 구간 2002-10 ~ 2015-12 의 평균 부호로 고정**, 검증 구간 2016-01 ~ 2026-10 에서 판정(기준 ④). 같은 구간의 평소(비만기) 날 평균과의 차이도 함께 보고
- 비용: 069500 동시호가끼리 왕복 0.03% (a·b·c·d 모두 시가/종가 체결)

## D3 — 배당락 (전 종목 일봉 2년 + 예탁원 배당)

- 배당락일: R' = 기준일 이하 마지막 거래일, 배당락일 = R' 직전 거래일, 권리부 마지막 날 = 배당락일 직전 거래일
- **실행 가능 배당수익률** = 같은 종목 직전 같은 종류(결산/분기/반기) 배당금 / 권리부 마지막 날 실제 종가 — 이번 배당금은 선택에 쓰지 않는다(옛 제도는 기준일 후 확정). 직전 기록 없으면 제외. 수익 계산에는 실제 받은 배당금을 쓴다
- 배당소득세 15.4% 차감, 왕복 0.27%
- 규칙(4): a 권리부 종가 매수 → 배당락일 시가 매도(+세후 배당) b 같은 매수 → 배당락일 종가 매도(+세후 배당) c 배당락 전 상승: 권리부 10거래일 전 종가 → 권리부 종가(배당 없음) d 배당락 후 회복: 배당락일 종가 → 5거래일 후 종가
- 배당수익률 문턱(2): ≥ 1%, ≥ 3% → 시험 8개
- 가격: 수익률은 수정 일봉(일반주 현금배당은 Creon 수정에 미반영 확인됨), 문턱·호가는 실제가
- 개발 구간: 배당락일 ≤ 2026-05-29 / 봉인: 2026-06-01 ~ 2026-10-08 (기준 ④ = 봉인). 기준 ②는 배당락 '분기'(달력 분기) 단위

## R — '내일 오를 종목' 순위 모델 후속 (next_day_ranker.py 모델 그대로)
- 모델·특징·파라미터·대상 필터(실제가 ≥ 1,000원, 20일 평균 거래대금 ≥ 5억)는 `20261011_vol_spike/next_day_ranker.py` 그대로. 라벨 지평 H=5(1주), 매월 재학습 전진 검증, 학습은 시험 월 이전 데이터만
- 리밸런싱: 5거래일마다(겹치지 않게), 신호 D 종가 → D+1 시가 진입 → D+6 시가 청산
- R1 회피 필터(전 종목): 기준 = 대상 전부 동일가중, 전략 = 모델 점수 하위 20% 제외 동일가중. 판정량 = 주별 (전략 − 기준) − 추가 회전 비용
- R2 회피 필터(대형주): 기준 = 직전 60일 거래대금 상위 30 동일가중(compare_algos 와 같은 정의), 전략 = 그중 점수 하위 20%(전 종목 기준 순위) 제외. 판정량 동일
- 회전 비용: 주마다 (0.5 × Σ|w_t − w_{t−1}|) × (0.27% + 왕복 2틱) — 기준과 전략 각각 자기 회전만큼
- 개발 시험: 2025-06 ~ 2026-05 (기준 ②는 분기) / 봉인: 2026-06 ~ 2026-10-08 (봉인 구간의 모델은 2026-05 까지 데이터로 학습 후 월 재학습 계속)
- 참고: 상위 20 직접 매수(1주)는 10-11 개발 구간에서 이미 t0.69 → 기준 ① 불합격이라 재시험하지 않는다
