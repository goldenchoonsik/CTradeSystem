## 데이터·구간

- 일봉: 수정주가, 2024-08-14 ~ 2026-10-08 / 1분봉: 무수정, 2024-09-12 ~ 2026-10-08
- **개발 구간**: ~ 2026-05-29 / **봉인 구간**: 2026-06-01 ~ 2026-10-08 — 개발 구간 합격 가설만 마지막에 1회 시험

## 공통 규칙
- 거래대금 배수 `vr` = 1분 거래대금 / 직전 20거래일 같은 분의 평균 거래대금 (최소 15일, 당일 제외)
- 가격: 1분봉(무수정) × 계수 f_D(수정 일봉 종가 / 무수정 일봉 종가) = 수정주가 기준
- 직전 20거래일 안에 거래정지(일봉 거래량 0) 또는 1분봉 누락일이 있으면 그날은 판정 제외
- 신호 봉 t 확인 후 **다음 봉 시가 진입** (Creon 1분봉 라벨 t = [t-1분, t) 체결)
- 실행 가능성 필터: 신호 봉 거래대금 ≥ 1억원, 진입은 신호 후 3분 안 첫 체결 봉 시가(없으면 이벤트 제외)
- 종목·날짜당 첫 신호 1건만 (겹친 진입으로 t 부풀리기 금지)
- 비용: 왕복 0.27%(수수료+매도세) + 슬리피지 시나리오 0 / 0.1 / 0.3 / 0.5% (판정 기준 max(0.3%, 왕복 2틱/진입가) — KRX 호가 단위표; 동시호가 체결 가설 H5 는 0.1%)
- 통계: 이벤트를 **날짜별 동일가중 포트폴리오 수익**으로 묶어 일별 시계열의 t (같은 날 테마 동조로 인한 부풀림 방지)
- 롱만 실행 가능(개인 공매도 불가). 숏 방향 수치는 참고로만 보고

H5 주의: 일봉 판정은 D 종가를 안다고 가정(15:20 동시호가 진입 시점엔 미확정) → 합격 시 1분봉 15:19 기준으로 재확인.
H4 주의: 실제 VI 기준가는 시가가 아니라 직전 단일가 — 1분봉 근사.

## 합격 기준 (모두 충족)
1. 판정 슬리피지에서 이벤트 평균 순수익 > 0, 일별 포트폴리오 t > 3
2. 개발 구간 분기별 부호 일관(분기 2/3 이상 양)
3. 개발 구간 마지막 3개월 양
4. KOSPI·KOSDAQ 따로 봐서 한쪽에서만 나오면 그 시장만 합격
5. 이후 봉인 구간 1회 시험에서 순수익 양·t > 2

## 변경 이력
- 2026-10-11 (1분봉 성과 확인 전): 신호 봉 거래대금 ≥ 1억원 필터·진입 3분 제한 추가 — 소형주는 같은 분 평균 거래량이 0에 가까워 vr 이 무의미하게 커지고, 무체결 분의 '시가'는 체결 불가 가격이기 때문.
- 2026-10-11 (1분봉 성과 확인 전): 거래량 배수→거래대금 배수, 수정주가 계수 적용, 정지·누락 후 20일 제외 — 테스트용 종목 선정 중 액면병합·분할(받은 680종목 중 10+)과 장기 거래정지(최대 392일)가 무수정 1분봉에 가짜 갭·가짜 고가 돌파·왜곡된 기준선을 만드는 것을 발견. 또 Creon 일봉 종가는 2026-09-14 부터 20:00 시간외 종가라 1분봉 종가와 직접 비교 불가 → 무수정 일봉을 따로 받아 같은 정의끼리 계수 산출.
- 2026-10-11 (1분봉 성과 확인 전): 판정 슬리피지를 고정 0.3% → max(0.3%, 왕복 2틱) 으로 강화 — 저가주는 1틱이 0.1~0.5%.
- 2026-10-11 (1분봉 성과 확인 전): 호가 단위(판정 슬리피지)와 후보 풀 '종가 ≥ 1,000원' 은 수정가가 아니라 그날 실제 가격(무수정) 기준 — 병합 전 실제가 267원 종목을 수정가 1,335원으로 보면 1틱 비용을 5배 과소평가.
- 2026-10-11 (1분봉 성과 확인 전): 특수 거래일(수능 10:00~16:30·새해 첫날 10:00 개장)은 장 일정 원장(krx_session)의 개장 시각만큼 당겨 평일 시각 창을 그대로 적용 — 고정 09:01~15:20/15:30 이면 수능일 종가를 장중 15:30 봉으로 잘못 잡는다.
