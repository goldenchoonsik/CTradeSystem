# 미국 임원 매수·실적 놀람 대략 판정 (2026-10-22)

질문: 미국 개별 종목에서 임원 지분 변동, 매출·순이익의 방향이 좋은 재료인가?
방식: 가진 자료(Yahoo 현재 상장 보통주 5,707종목 + SEC 일괄 자료)로 대략 판정. 살아남은 종목만이라 매수 효과는 부풀려지는 쪽 → 없으면 '없음' 확정, 있으면 상폐 가격으로 재확인.

## 결론

| 재료 | 확인된 크기 | 칸 |
|---|---|---|
| 기회주의 임원 매수 · 소형주 | 같은 회사 무작위 날짜 대비 60일 +2.7%(2006~18, CI +0.4~+5.4) / +3.4%(2019~26, CI +1.0~+5.8), 20년 중 17년 양. 비용 후 포트폴리오 연 11.3% / 12.3% vs 소형 기준 9.8% / 3.7% | 작게 실험 (종목 고르기 필터) |
| 임원 매수 · 대형주 | 0 또는 음(2019~26 −1.9%) | 버림 |
| 일상적 임원 매수(매년 같은 달) | 0 | 버림 |
| 매출·순이익 전년비(10-Q 제출 후) | 좋은/나쁜 놀람 vs 전체 60일 ±1% 이내, 두 기간 부호 불일치, 비용 미달 | 버림 |
| 대형주 나쁜 놀람 피하기 | 2011~18 60일 −0.76%, 2019~26 +0.18% → 피할 가치 없음 | 버림 |

**같은 잣대(QQQ)**: 기회주의·소형 포트폴리오는 비용 후 2006~18 연 11.3%(MDD −50%) vs QQQ 11.8%(−53%), 2019~26 연 12.3%(−42%) vs QQQ 22.4%(−35%). 신호는 소형주 안에서 진짜지만, 소형주 자체가 QQQ에 크게 뒤져 절대 수익으로는 QQQ를 못 이김.

## 2차: 임원 말고 '조직' 매수 (같은 날 추가)

대조군 = 13G(5% 이상 단순 투자 공시, 정보 없을 것) 의 같은 기간·크기 실제 초과수익. 60일, 비용 후 '대조 대비' 차이(%):

| 신호 | 소형 06~18 | 소형 19~26 | 대형 06~18 | 대형 19~26 | 칸 |
|---|---|---|---|---|---|
| 임원 기회주의 매수 | +0.9 | +2.3 | +0.7 | +0.6 | 작게 실험(유지) |
| 10% 대주주 매수(임원 아님) | +1.2 | 0.0 | −0.1 | −0.6 | 버림에 가까움 |
| 13D 새 대상(5%↑, 경영 개입 가능) | −0.5 | −0.2 | −0.8 | −1.8 | 버림 |
| 13D 반복 신고인(≥10건, 전문 행동주의) | 0.0 | +3.3 | −0.7 | +3.3 | 판별 불가(n 35~107) |

- 13D 는 공시 전 10일 +0.5~1.7%, 공시일~다음 날 +0.8~1.3% 가 이미 반영 — 우리가 살 수 있는 시점 이후엔 남는 것 없음(Brav 외 2008 의 ±20일 +7% 는 대부분 공시 전후 며칠 몫).
- **함정**: 같은 회사 무작위 날짜 대조가 2019~26 소형에서 아래로 치우침(13G 대조군도 '타이밍' +2.9%) → 1차 표의 2019~26 '타이밍' 값은 부풀려짐. 13G 대조 비교로도 임원 기회주의 매수는 두 기간 양(+)이라 결론 유지.
- 스크립트: `event_eval.py`(공통 평가), `h3_owner10.py`, `fetch_edgar_index.py`(EDGAR 분기 색인 2006~), `h4_13d.py`

## 파일
- `sec_bulk_fetch.py` SEC 일괄 zip 수집(UA=환경변수 SEC_USER_AGENT) → staging/us_sec_bulk/raw
- `build_form4.py` Form 4 장내 매수·매도 표, `coverage.py` 가격 커버리지(2006 25% → 2026 88%)
- `panel.py` 일별 총수익률·종가·거래대금 패널
- `h1_insider.py` 임원 매수 묶음별 초과수익(달력 시간 t) → h1_results.csv
- `h1_placebo.py` 같은 회사 무작위 날짜 대조(생존 편향 점검) → h1_placebo.csv
- `h1_vs_qqq.py` 실제 굴린 포트폴리오 vs QQQ → h1_vs_qqq.csv
- `build_fsds.py` 10-Q 매출·순이익(같은 공시 안 작년 같은 분기 비교값), `h2_earnings.py` → h2_results.csv

## 함정·한계
- 초과수익 기준 = 같은 날 같은 거래대금 5분위. 일수익 +200%↑/−80%↓ 은 자료 오류로 제외.
- 생존 편향: 같은 회사 무작위 날짜 대조는 소형에서 ≈0 또는 음 → 회사 단위 편향은 효과를 만들지 않음. 남는 것은 '곤경 시기 매수 후 살아남은 회사만 보임' 시점 편향 — 커버리지 71~88%인 2019~26 에서 효과가 오히려 커서 착시 가능성은 낮다고 판단, 확정은 상폐 가격(EODHD) 필요.
- 실적 정보일 = 10-Q 제출일(보도자료 8-K 가 먼저인 회사는 첫 반응 놓침). 10-K(4분기) 제외.
- 비용: 왕복 소 0.8%·중 0.3%·대 0.1% 추정. 소형은 60일 회전이라 연 약 3.4% 비용이 큼.
- CMP 분류(직전 3년 매년 거래) 때문에 기회주의 사건은 2009년부터 실질.
