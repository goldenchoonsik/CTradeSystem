## 개발 판정 (연말 2013~2022): 불합격 — 조건 5개 중 1·2·3 실패

- 비용 후 초과 +0.83% t1.25, 양수 5/10.
- **자연 실험이 반대 방향**: 기준 10~15억 해 +0.48% < 25~50억 해 +1.34%. 대주주 매도가 가장 화제였던 10억 시기 2020~2022 는 3해 모두 음(−1.4~−1.6%). → 대주주 기준으로는 설명되지 않음.
- 남은 사실: 올해 오른 종목은 11월 말~매도 마감일에 대조군보다 −1.9%(t−3.2), 마감 뒤 반등 비용 전 +1.4%(위약 월 대비 +1.56%p, t2.43). 다만 연말 패턴이 기준액과 무관하고, 비용 후 유의하지 않음.
- 조건 4(위약 대비) 통과는 **배당락 착시 가능성**: 매도 마감일 D = 배당 받는 마지막 매수일이라 반등 구간 첫날(L−1)이 배당락일. 가격수익만 쓰므로 배당이 큰 종목(대조군 평균)이 더 깎임 → 배당이 작은 '올해 오른 종목'의 초과가 부풀 수 있음(크기 미측정).
