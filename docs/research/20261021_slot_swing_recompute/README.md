## 2. 원본 → 두 줄 수정 → 정정 엔진

두 줄 수정 = 원본 코드에서 이중 계산 두 곳만 고친 것(나머지 결함은 그대로).
정정 엔진 = `swing_engine.py`: 슬롯별 실제 보유수량, 연도별 거래세 +0.07%, 매수 0.05%, 현금은 기준금리(미국은 국채 3개월).
체결 방식 두 가지를 모두 계산했다.
- 종가 체결: 원본과 같은 판정, 종가 동시호가에 체결
- 장중 체결: 시가 진입, 손절·익절은 장중 지정가, 갭이 생기면 시가에 체결

## 3. 해석
- **진입 신호(눌림목+수급, 바닥 거래량 폭증)는 쓸모가 없다.** 12개 비교(6개 구성 × 체결 2방식) 중 신호가 대조군을 이긴 것은 B·C의 4건뿐이다. 그 넷도 원금의 43~82%를 잃은 구성이다.
- **잘 된 것처럼 보이는 숫자는 명단에서 나왔다.** A와 Titan10은 '나중에 오를 종목'을 알고 고른 명단이라, 그냥 들고만 있어도 +684%, +11,271%다. 스윙은 그 상승의 일부만 먹었다. 당시 알 수 있던 명단(2012년 말 미국 시총 상위10)으로 바꾸면 스윙이 그냥 보유와 QQQ 모두에 진다.
- **익절 상한·손절 구조가 상승 추세의 꼬리를 잘라 버린다.** 미국 Titan10에서 스윙 세후 13.6억 vs 보유 88.9억.
- 체결 방식에 따라 A1이 +269% ↔ +25%로 흔들린다. 결과가 실행 세부에 이렇게 민감하다는 것 자체가 엣지가 없다는 신호다.
