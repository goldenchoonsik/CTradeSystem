# 사전등록 v4 — 시총 상위 20 종목, 외국인 매수 때 같이 사고 매도 때 같이 파는 추종 (2026-10-25)

사용자 지시(2026-10-25): 코호트 방식 없이, 시총 상위 20개를 정해 외국인이 살 때 같이 사고 팔 때 같이 판다. **같은 데이터 위의 사후 기술 통계이며 검정이 아니다. 최종 판단은 2027년 전진 기록.** 정의 고정 후 변경 금지(변경은 새 문서). 사전 기대: 단기 외국인 수급의 종목 수준 예측력은 이전 연구에서 ≈0(60일 매집 후 초과 없음, 월별 선행 IC≈0.02)이라 기각 가능성이 높다.

## 1. 정의
- 유니버스: 매월 마지막 거래일 시점 시총 상위 20 (다음 달 내내 적용, 그 사이 시총 순위가 바뀌어도 월말에 갱신). 신호 결측(폐지·미상장)은 현금.
- 외국인 매수 신호: 종목별 외국인 보유 수량 `foreign_hold_qty`(daily_ext)의 W거래일 변화 > 0 이면 "매수 중"(보유), ≤ 0 이면 "매도 중"(현금).
- W ∈ {5, 20, 60} 거래일 — 3개를 사전 고정, 전부 보고(선택 금지).
- 체결 지연: 신호는 d일 장 마감 후 확정 → d+1 종가 체결 → d+2 수익부터 반영(보유 수익은 d+1 종가→d+2 종가). 즉 포지션(d) = 신호(d−2).
- 비중: 각 종목 슬롯 1/20 동일, "매도 중" 슬롯은 현금(수익 0). 합계 비중 ≤ 100%.
- 비용: 포지션 변경(매수 또는 매도, 월말 유니버스 교체 포함) 시 변경 비중 × 편도 0.185% (왕복 0.27% + 슬리피지 0.10% = 0.37%).
- 구간: 2014-01-02 ~ 데이터 끝(워밍업 60일).

## 2. 비교
- A: 같은 유니버스 상시 보유 동일가중(비용은 유니버스 교체분만).
- B: 같은 유니버스 시총가중(비용 0), 코스피 가격지수.
- A_blend: A 수익 × (평균 투자 비중). 즉 "그냥 덜 투자한 효과" 대조.

## 3. 사전 기준 (참고용)
각 W 에 대해 아래를 모두 충족하면 "전진 기록 후보", 아니면 "기준 미충족":
1. 비용 후 샤프 > A 의 샤프.
2. 비용 후 CAGR > A_blend 의 CAGR (덜 투자한 효과를 넘어섬).
3. 2025 제외 후에도 1·2 동일 충족.
4. MDD ≥ A 의 MDD (낙폭이 더 나쁘지 않음).
(3개 중 1개가 통과해도 다중비교 주의로 표기.)

## 4. 금지
W·유니버스 크기(20)·체결 지연·비용·기준을 바꿔 재평가 금지.
