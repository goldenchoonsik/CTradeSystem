# 사전등록 — 외국인 지분 36개월 증가 신호 매수 전략 (2026-10-25)

사용자 승인(2026-10-25)으로 고정. 이 문서 sha256 은 `PREREGISTRATION.sha256` 에 기록. 고정 후 정의·합격선 변경 금지(변경 시 새 문서로 사유 명시).

## 1. 가설
시총 상위 200 중, 직전 36개월 외국인 지분율 증가폭이 큰 종목(직전 36개월 수익 중립화 후)을 12월에 동일가중으로 사서 12개월 보유하면, 왕복 0.27%+슬리피지 차감 후에도 상위 200 동일가중 대비 초과수익이 난다.

## 2. 정의 (전부 확정)
- 데이터: `DataVault/staging/kr_equity/derived/{gold_1d,prices_1d}.parquet`. 가격=수정종가 `close`, 시총=`market_cap`, 지분율=`foreign_hold_pct`.
- 형성일 t: 매년 12월의 마지막 거래일. 보유: t 종가 매수 → t+12개월 마지막 거래일 종가 매도(상장폐지는 마지막 종가).
- 유니버스: t 시점 시총 상위 200(상장폐지 예정 종목 포함, 당시 시점 기준).
- 신호 점수: `dp = fh(t) − fh(t−36개월)` (%p). 둘 중 하나라도 결측이면 신호 없음(후보 제외).
- 수익 중립화: 같은 t의 후보 횡단면에서 `rank(dp)` 를 `rank(직전 36개월 수익)` 에 OLS 회귀, 잔차를 점수로 사용.
- 제외 필터: 36개월 창 안 월말 지분율 최댓값 − fh(t) ≥ 3%p 이면 제외("상단 후 하락").
- 선택: 필터 통과 후보 중 잔차 점수 상위 20%(올림), 동일가중.
- 벤치마크: 같은 t의 유니버스 200개 전부 동일가중(폐지 종목 포함). 보조: 코스피200 지수(index_1d 가용 시).
- 비용: 선택 포트폴리오에만 연 1회 전량 회전 가정, 왕복 0.27% + 슬리피지 0.05%×2 = **0.37%p** 차감. 벤치마크는 비용 미차감(보수적).
- 형성 연도: 36개월 이력 필요(데이터 2013-01~) → 첫 t = 2016-12.
  - **개발**: t = 2016~2022-12 (7개, 보유 종료 2023-12).
  - **봉인**: t = 2023-12, 2024-12 (2개, 1회만 실행). t=2025-12 는 보유 미완이라 제외.
  - 봉인 표본이 2개뿐이라 검정력이 낮음을 사전에 인정한다.

## 3. 생존 편향 처리 (코드 연속성 보정 대체안)
상장폐지 종목은 지분율이 없어 신호를 못 만든다(상위 200 중 연 3~22개, 총 39코드). 보정 데이터가 없어 시나리오로 처리한다.
- S0(기본): 신호 있는 종목만 후보. 벤치마크는 폐지 종목 포함.
- S1(중립 편입): 신호 없는 폐지 예정 종목(해당 t 유니버스에 있었고 이후 폐지된 코드)이 선택 비율(20%)만큼 선택군에 들어간다고 보고, 해당 종목의 실제 보유 수익을 비중 0.2로 선택군 평균에 혼합.
- S2(최악): t 이후 12개월 내 폐지된 종목 전부가 선택군에 포함. (상한 편향 점검용, 합격선에 쓰지 않고 보고만)
- **합격은 S0 와 S1 둘 다 충족해야 한다.**

## 4. 합격선 (개발 구간, 비용 후)
모두 충족해야 봉인 구간을 실행한다.
1. 연 평균 초과수익(선택 − 벤치마크 − 0.37%p) > 0.
2. 종목 단위 초과수익(종목 수익 − 벤치마크 평균) 중앙값 > 0.
3. 7개 연도 중 4개 이상 비용 후 초과 > 0.
4. 형성 2022-12(2023 보유) 제외 후 연 평균 초과 > 0. (2023~24 편중 점검)
5. S1 에서 1번·4번 동일 충족.

봉인 합격(참고용, 표본 2): 2개 연도 평균 비용 후 초과 > 0 이고 1개 이상 연도 양(+). 이 결과는 부호 확인일 뿐 유의성 주장 금지.

## 5. 민감도 (보고만, 합격 불영향)
- 월별 형성(매월 말, 12개월 보유, 겹침 코호트): 개발 2016-12~2022-12 월별 코호트 평균.
- 상위 10%/30%, 창 24/48개월, 유니버스 100/300.
- 중립화 없음(원시 dp 순위).
- 수익 상위 5개 종목 제거.

## 6. 실행·판정 규칙
- 스크립트: `foreign_strategy.py` (개발 모드는 봉인 연도를 읽지 않음, `--sealed` 는 합격 시에만 1회).
- 개발 불합격 시 정의 수정·재시험 금지, 결과만 기록(크기 포함 보고).
