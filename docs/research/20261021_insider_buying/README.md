- 사건: 개인 임원(등기·비등기) 보통주 장내매수−장내매도 > 0, 접수일 다음 거래일 종가 매수, 같은 회사 60거래일 겹침 제거, 유니버스(≥1,000원·20일 거래대금≥5억) → 374개.
- 비용 0.57% 후, 같은 시총 5분위 동일가중 대비: 20일 −0.70%, 60일 +0.38%(t1.72), 120일 +2.98%(t2.09). 그러나 중앙값 −2.1%/−1.0%, 승률 44~47%,
  **상위 5개(+160~266%) 빼면 60일 −0.96%·120일 +0.17%** — 평균은 몇 개 대박주 몫. 60일 사건 수익 중앙 +3.45% = 기준 중앙 +3.44%.
- 대표이사 매수(69) 60일 +0.08%·120일 −1.60%, 하락 후 매수(63%, '책임경영' 형) ≈0; 연도별 60일 2017 −5.4%·2020 −3.5%.
- 결론: 일반적인 임원 매수에는 엣지가 안 보임. 전량 수집(약 15만 건, 8일)은 권하지 않음.
