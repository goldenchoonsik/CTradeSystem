3. 배수 **변화**(월)는 실질금리·기대 물가·신용 스프레드 중 무엇과 함께 움직이는가?

5. 그 정보로 연 1회 주식/현금 비중을 기울이면 같은 평균 비중의 고정 배분보다 나은가?

## 시점 규약 (월 t 의 신호에 쓰는 값)

- 이익·배당: **3개월 전** 값(E_{t−3}, D_{t−3}) — 분기 실적 발표 지연. CAPE_pit = P_t / E10_{t−3}, E10 = 직전 120개월 실질 이익 평균.
- CPI: 1개월 전. 금리·가격·BAA·TIPS: 월 t 평균(월말에 알려짐).
- 실질금리 대리(TIPS 이전): real10 = GS10_t − 직전 10년 연평균 CPI 상승률(Shiller ECY 방식). ECY = E10_{t−3}/P_t − real10.
- 신용 = BAA − GS10. 장단기 = GS10 − T-bill(RF×12). 물가 = 12개월 CPI 상승률. 물가 변동성 = 직전 60개월 월 CPI 변화 표준편차 × √12.
- 월 t 신호는 월 t+1 부터의 수익(French 월말)과 짝짓는다. 10년 수익은 Shiller 실질 총수익 가격으로 t → t+120.

## A. 설명 (판정 없음 — 크기만 보고)

**A1 배수 변동의 원천 분해 (Cochrane 식 현재가치 항등식, 연 단위 12월).**
dp_t ≈ Σ_{j=1..15} ρ^{j−1} r_{t+j} − Σ ρ^{j−1} Δd_{t+j} + ρ^{15} dp_{t+15}. 각 항을 dp_t 에 회귀한 기울기 = 미래 수익 몫·배당 성장 몫·남은 배수 몫. ρ = 1/(1+exp(평균 dp)). 실질 기준. 시작연도 1871~2010 전체, 1871~1945, 1946~2010. 같은 식을 E10(이익)으로도(근사 — 배당성향 변화 오차를 잔차로 보고).

**A2 배수 수준.** log CAPE_pit 를 real10·물가·물가 변동성·신용에 회귀(신용은 1919~). 시대 1881~1949 / 1950~1997 / 1998~2026-10 따로. 물가 구간(<0, 0~2, 2~4, 4~6, ≥6%)별 평균 CAPE 를 시대별로.

**A3 배수 변화의 동행 설명(월).**
(i) 2003-01~ : Δlog P 를 ΔTIPS10·Δ기대물가(GS10−TIPS10)·Δ신용에 회귀 — 표준화 계수, 단독 R², 전체 R². 2003~2019 / 2020~ 나눠서.
(ii) 1953~ : Δlog P 를 ΔGS10·Δ물가·Δ신용에 회귀, 1953~1997 / 1998~ 나눠서.

## B. 예측 (판정 있음)

**B1 10년 실질 총수익 표본외.** 예측 시점 t = 1911-01 ~ 2016-10(실현 확인 가능한 마지막). 각 t 에서 **실현이 끝난 짝(시작 ≤ t−120)만** 학습.
- M0 과거 평균(기준선) · M1 log CAPE_pit 확장창 회귀 · M2 1/CAPE_pit(적합 없음) · M3 D/P + 과거 실질 배당 성장률 평균(고든).
- 보조 B1b: 10년 주식−채권 실질 초과수익(Shiller)을 ECY 확장창 회귀 vs 과거 평균.
- 지표: 표본외 R²(=1−SSE/SSE_M0), RMSE(%p/년), 실현을 예측에 회귀한 기울기(보정). 반쪽: 예측 시점 1911~1959 / 1960~2016.
- **판정: 두 반쪽 모두 표본외 R² > 0 → '유효'.** 유효 모델들의 2026-10 추정치 범위와 RMSE 를 현재 기대수익으로 보고. 겹치는 표본이라 t값은 내지 않는다(독립 10년 ≈ 10개).

**B2 1·12개월 초과수익 표본외(Goyal–Welch 방식).** 대상 French Mkt-RF(로그, 다음 h 개월 합). 신호 dp·ep10(=−log CAPE_pit)·ECY·T-bill·장단기·신용·물가, 단변량 확장창 회귀 + 평균 결합(Rapach–Strauss–Zhou). 학습 1927~, 표본외 1950-01~. 지표 R²_OOS(기준 = 확장창 평균). **판정: 두 반쪽(1950~1989 / 1990~) 모두 R²_OOS > 0 → '유효'.**

**B3 연 1회 비중 기울기(실전 형태).** 매년 12월 말 결정, 다음 1년 유지(월별 표류, 연 1회 재조정). 자산 = CRSP 시장(Mkt-RF+RF) / T-bill(RF).
- V: w = 1.0 − 0.4 × pct_t, pct_t = 1881-01 부터 그 시점까지의 CAPE_pit 백분위(0~1) → w ∈ [0.6, 1.0].
- 비교: S-avg = V 의 그 반쪽 평균 비중 고정, S80 = 0.8 고정.
- 기간 1927~2025, 반쪽 1927~1975 / 1976~2025. 지표 CAGR·변동성·샤프·MDD(월 경로).
- **판정: 두 반쪽 모두 V 가 S-avg 보다 CAGR 와 샤프 둘 다 높음 → '기울기 실전 후보'. 아니면 '기울기 버림'(기대수익은 맥락 정보로만).**
