# 사전등록 — 미국 주가와 PER·PBR 등 지표의 관계, 현재 지표 vs 미래 지표 (2026-10-23)

결과를 보기 전에 고정한다. sha256 은 `PREREGISTRATION.sha256`. 고친 내용은 '변경 기록'에만.

## 질문

1. **동행**: 같은 시점에 종목 간 PBR·PER 차이는 ROE·성장으로 얼마나 설명되나?
2. **현재 지표 → 미래 지표**: PER 이 높은 회사는 실제로 이익이 더 늘었나? PBR 이 높은 회사는 높은 ROE 를 유지했나? (시장 기대가 맞았나)
3. **현재 지표 → 미래 수익률**: E/P(=1/PER)·B/P(=1/PBR)·S/P·D/P·CF/P·ROE·총이익/자산·과거 성장이 다음 1년·3년 수익률과 얼마나 상관있나?
4. **미래 지표 → 같은 기간 수익률(완전 예지, 미래참조 의도적)**: 다음 1년·3년 실제 이익 변화를 미리 알았다면 수익률과 상관이 얼마나 되나? — 3번과 비교해 '주가를 움직이는 것'의 크기를 잰다.
5. **장기(생존 편향 없음)**: 1926~2026 Ken French 정렬 포트폴리오로 싼 종목(B/M·E/P·CF/P·D/P 상위 10%) − 비싼 종목(하위 10%) 수익 차를 10년대별로. 대형주만(2×3 Big Value − Big Growth)도.
6. **예상 지표(현재 한 시점)**: 2026-10 현재 S&P500 의 Yahoo 예상 PER·예상 이익 성장 vs 과거 기준 PER — 분포와 상관만(과거 검증 불가: 애널리스트 예상치 이력은 유료).

## 자료

- 단면: 당시 S&P500 구성 종목(fja05680 명단), 분기 마지막 거래일 s = 2009-12 ~ 2026-06. 가격 = Yahoo 총수익(현재 상장만 → 생존 편향, 빠진 비율 보고). 재무 = SEC companyfacts 연간(FY) 값 중 **filed ≤ s** (지표), 미래 지표는 s+1년·s+3년 시점에 공시된 최신 FY.
- 장기: Ken French Portfolios_Formed_on_{BE-ME, E-P, CF-P, D-P}, 6_Portfolios_2x3 (가치가중 월 수익).
- 예상: Yahoo quoteSummary(defaultKeyStatistics·financialData·earningsTrend), 2026-10-23 현재 S&P500(2026-08-18 명단).

## 지표 정의

E/P = 최근 FY 순이익 / 시총, B/P = 자본 / 시총, S/P = 매출 / 시총, CF/P = 영업현금흐름 / 시총, D/P = 12개월 배당 / 가격, ROE = 순이익 / 자본(자본>0), GP/A = 매출총이익 / 자산, 과거 성장 = 매출 3년 연성장. 시총 = 분할 보정 종가 × 주식 수(공시일 이후 분할 반영, build_fund.py 방식).
미래 이익 변화 = (미래 EPS − 현재 EPS) / 현재 가격 (적자 포함 가능한 척도), 보조로 흑자→흑자 log EPS 성장. 미래 ROE = s+1년·s+3년 시점 최신 FY ROE.

## 측정

- 분기별 단면 **순위상관(Spearman IC)** 의 평균, Newey-West t(겹침 지연: 1년 3·3년 11). 5분위 상위−하위 연환산 수익 차.
- 구간: **앞 = 시작 2010~2017, 뒤 = 2018~** (3년은 2023-06 시작까지).
- 판정(설명용 꼬리표): 두 구간 같은 부호이고 각 구간 |평균 IC| ≥ 0.03 → '일관', 아니면 '불안정'.
- 동행: 분기별 단면 회귀 log PBR ~ ROE, log PER(흑자만) ~ 미래 3년 성장의 R² 평균.
- 장기: 10년대별 상위−하위 연환산 차, 전체 t.
