## 매매 규칙 (고정)
- 대상: 유니버스(우선주·스팩 포함), 전날 실제 종가 ≥ 1,000원, 20일 평균 거래대금 ≥ 5억, 직전 20일 거래정지 없음
- 신호 = D-1 장마감까지의 값, 진입 = D 시가(동시호가)

| 신호 | 정의 |
|---|---|
| S1 거래 폭증 초기 | 전날 거래대금 ≥ 평소 5배, 전날 수익 −5% ~ +10%, 직전 20일 상한가 없음 |
| S2 소외 후 거래 증가(첫 상한가 모양) | 한 달(D-21→D-1) 누적 ≤ 0, 직전 5일 거래대금 중앙 ≥ 평소 1.5배, 직전 5일 누적 −5% ~ +5%, 직전 20일 상한가 없음 |
| S3 상한가 확률 모델 상위 10 | results.md 의 LightGBM(전날 특징)을 2025-12 까지로 학습, 매일 점수 상위 10 (2026-01~ 만) |
| S4 급락 후 거래 폭증 | 전날 수익 ≤ −10%, 전날 거래대금 ≥ 평소 5배 |

| 청산 | 정의 |
|---|---|
| X1 당일 | D 종가 |
| X2 5일 단순 | D+4 종가 |
| X3 5일 익절·손절 | +20% 도달 시 그 가격 익절, −10% 도달 시 그 가격 손절(시가가 이미 넘었으면 시가), 같은 날 둘 다면 손절 먼저(보수), 아니면 D+4 종가 |

시험 = 4 × 3 = 12.
- 평소 거래대금 = D-80 ~ D-21 거래대금 중앙값 (한 달 이전 평소)
- 비용: 왕복 0.27% + 판정 슬리피지 max(0.3%, 왕복 2틱/진입 실제가) — A 항목과 동일 (시가 진입·장중 손절은 호가 공백 위험)
- 통계: 진입일별 동일가중 포트폴리오 수익 → 다일 보유는 5거래일 간격으로 솎아 t
- 계좌 시뮬(참고): 자본 10칸, 한 신호 = 1칸, 빈 칸이 없으면 건너뜀, 같은 종목 중복 보유 금지, 실현 손익으로 복리
