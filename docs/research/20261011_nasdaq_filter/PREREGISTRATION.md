## 정의 (보유 시작 전 정보만)
- q = NQ(라벨 08:55 종가) / NQ(라벨 15:29 종가, 전 거래일) − 1  ← 08:56 확정, KRX 개장 전
- gap = K200(09:01) / K200(전일 15:30) − 1 (09:01 에 확정, 진입가)
- 진입 = K200 09:01 종가, 청산 = 10:00 또는 15:30 종가. 롱 = 069500, 숏 = 인버스 ETF(매도세 없음)
- 비용: 왕복 0.05% (ETF 1틱 + 수수료)
