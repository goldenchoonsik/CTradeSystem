# 지수 정기변경 편입·편출 사건 연구 (2026-10-21~22)

질문: 제미나이 '리밸런싱 이벤트 드리븐' — 편입 40~50일 전 선취매 → 편입일 15:30 동시호가에 패시브에게 비싸게 넘김, "승률 75~80% 확정".

## 데이터

- `kospi200_changes.csv`: 코스피200 정기변경 2013-06~2026-06(2019년까지 6월만, 12월 변경은 2020-12부터) 편입 132·편출 137 + 특례편입·수시변경(본표 제외). 출처 = 국내 기사 2곳 이상 대조(거래소 데이터 포털은 로그인 필요로 실패).
- 10-20 MSCI 연구의 손 입력 명단 52건 중 14건(27%)이 공식 목록과 다름(회차 틀림·편입 아님) → 그 연구 결과는 인용 금지.
- 가격: staging/kr_equity prices_1d(수정·상폐 포함), 1분봉: staging/vol_spike_universe(2024-09-12~).
- 기준: 규모 맞춤 지수(코스피200 사건 = 코스피 중형주 U003, MSCI = 코스피 종목은 코스피200 동일가중 U155·코스닥 종목은 코스닥 대형주 U202). 코스피200(U180) 기준도 `out_k200.txt` — 결론 같음.
- 비용: 매수 0.05% + 매도 0.07% + 연도별 거래세.

## 결론
1. 제미나이 원안(40일 전 예측 매수 → 편입일 종가 매도)은 2022년 이후 예측이 전부 맞아도 코스피200 손실·MSCI 무의미. 2021년까지는 실제로 컸다(연 +12~33%p, 완벽 예측 상한) — 선취매 경쟁으로 사라진 미국 S&P500 경로와 같다.
2. "편입일 동시호가에 비싸게 넘긴다"는 최근 실측에서 0(MSCI) 또는 반대(코스피200 −0.9%).
3. 확실한 두 가지: 편입 종목은 편입일 뒤 5일간 진다(−3~−4%), 편출 종목은 발표 전후로 계속 진다(−5~−7%). 개인 공매도는 어려우니 쓰임새는 '보유 종목이 편출 후보면 자료 마감 직후 매도', '편입 종목을 편입일 이후 들고 있지 않기'.
4. 작은 엣지: MSCI 편출 종목 편입일 동시호가 매수 → 다음 날 시가 매도(비용 후 하룻밤 +0.1~0.5%, 연 4회).
