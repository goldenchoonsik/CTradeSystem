# 외국인 꾸준한 매수 + 주가 정체 → 상승 전환 종목 (2026-10-26)
정의: 120거래일 창, 외국인 누적 순매수 ≥ 상장주식수의 1.0%p, 순매수일 비율 ≥ 55%, 창 수익 ≤ +5%, 시총 상위 500. 연속 충족은 한 에피소드(신호일=첫 충족일). 데이터는 daily_ext 기준 2026-10-08까지(10-24 통합 업데이트 미완).
- 에피소드 3,891개(807종목). 이후 120일 +20% 이상 오른 것 687개 → `stall_then_rise.csv`(전수 목록). 500일 내 +20% 도달 65%, 도달까지 중앙 90일, 도달 전 최대낙폭 중앙 −21%.
- **그러나 사전 구별력 없음**: 120일 +20%↑ 비율 18.5%(기저율 21.7%), 시장 대비 초과 중앙 −0.1%p. 같은 정체인데 외국인이 판 종목(+1.8%p, 20.2%)·정체 전체(+0.9%p, 19.6%)와 차이 없음.
- 특징별(c120·U·R120·정체 길이) 4분위 전환율 차이 작음(16~22%). 유일하게 정체가 가장 길었던 4분위만 11%로 낮음.
- 연도별 변동 큼(2025 초과 +12.3%p, 2020·2021 −5%p대) = 시장 국면 영향. 승자 목록은 사후 선택이라 매수 근거 아님.
- 현재 진행 중 77개: `stall_current.csv`. 스크립트: stall.py, extra.py. 생존 편향(지분율 현재 상장 종목) 미보정.

## 최적화 시험 (optimize.py, optimize_grid.csv) — 개발 2014~2021 / 검증 2022~
격자 756조합(창 W 20~250일 × 매집 상위 q 10·20·30% × 순매수일비율 0.5~0.6 × 창수익 상한 −10~+10% × 보유 20·60·120일), 비용 0.27% 차감, 시총 상위 500.
- 단순 '시장 중앙 대비 초과'는 95%가 양수지만 **착시**: 평균−중앙값 왜도 + 정체 종목 자체의 반등. 같은 날 '정체만(매집 조건 없음)' 대조군이 개발 +2.9%·검증 +3.0%로 선정군(+1.9%·+2.7%)보다 높음.
- 매집 효과만 분리(선정−대조군): 평균 검증 −0.3%p, 개발 상위 10% 조합 개발 +0.02%p → 검증 −0.07%p, 개발·검증 순위상관 0.20. 즉 **최적화해도 외국인 매집은 정체 반등에 보탬 없음**.
- 유일한 약한 단서: W=20일·매집 상위 10%·순매수일 ≥0.50~0.55·창수익 ≤ −10%·보유 120일 → 대조군 대비 개발 +1.3~1.4%p, 검증 +2.0~2.7%p(n≈750). 이웃 조합 일관(0.53/1.52 등)하나 756개 중 선택이고 일부 기울기만 유지(-0.1 아닌 rmax는 음). 확정 아님.
- 파라미터별: 보유가 길수록 높음(왜도), 창이 짧을수록 검증 양호(W20 3.6% → W250 1.1%).
