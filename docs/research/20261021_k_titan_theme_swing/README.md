## 3. 핵심 인사이트 & 교훈

### 1) 왜 Model 1 (핵심 산업 테마 대장주)은 +428% 폭발적 성과를 냈는가?
- 기존 지수 초대형주(삼성전자, 현대차)에만 갇혀 있던 자금을 **시대별 주도 테마의 1등 대장주(한화에어로스페이스, 알테오젠, HD현대일렉트릭, 에코프로 등)**로 분산 배치.
- 2024년 코스피 지수가 **-11.9% 급락**할 때도, Model 1은 **+56.3%**라는 경이적인 알파를 기록.
- 대장주는 눌림목(20일선)에서 강력한 기관/외인 방어 수급이 들어오므로 승률 54%, 손익비 2.02로 계좌가 가파르게 우상향.

### 2) 왜 Model 2 (동적 거래대금/급등주)는 -87% 참패했는가?
- 시장 거래대금 1위와 단기 급등만 보고 동적으로 종목을 따라다니면, **"테마의 3~4차 파동 상투(설거지 구간)"**에 진입하게 됨.
- 급등한 상태에서 20일선 눌림목을 노렸으나, 테마 소멸로 20일선이 지지가 되지 않고 지하실(-20%~-50%)로 처박히며 칼손절(-7%)이 연쇄 폭발함.
- **결론: "테마 대장주는 잡주/찌라시 급등주를 쫓는 것이 아니라, 펀더멘털과 산업 실체가 있는 메이저 섹터의 1등주들을 사전에 선정해 두어야만 승리한다."**
