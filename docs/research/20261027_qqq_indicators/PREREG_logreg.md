# 롤링 10년 로그회귀 이격 규칙 사전등록 (2026-10-27)
신호: z = (ln P − 최근 2520거래일 로그 선형회귀의 오늘 값) / 같은 창 잔차 표준편차. 모두 t 종가까지의 정보, t+1부터 적용.
R1: z>1.5 이면 현금, z<0.5 로 내려오면 재진입 (상태기계). R2: 비중 = clip(1 − 0.4·max(z,0), 0, 1).
파라미터 탐색 없음. 비용 편도 0.05%, 현금 T-bill, 보유일 배당 0.6%/년 가산.
대상: SPY QQQ DIA IWM XLK XLF XLE XLV XLP XLU (창 만기 후부터).
판정 (모두 충족해야 '근거 있음'): (a) 자산별 CAGR이 단순보유를 이긴 자산 ≥ 7/10, (b) 전 자산 평균 CAGR차 > 0, (c) 샤프 우위 자산 ≥ 7/10,
(d) 연말 z vs 다음 해 수익의 겹치지 않는 표본 풀링 순위상관 < 0 이고 연도 군집 부트스트랩 95% 구간이 0 미포함, (e) R1 이 무작위 런 순서 뒤섞기 상위 10% 안(자산 중앙값).
