# 미국 동행성 높은 한국 종목 단순 보유 (PREREG.md sha256 고정 후 comove_select.py, 출력 comove_select.csv; 2026-10-26)
방법: 매년 12월 말 시총 상위 300(보통주, 상폐 포함, 당시 기준) → 직전 104주 주간 수익의 S&P500 상관으로 5분위 → 이듬해 12개월 동일가중 보유(비용 무시). 형성 2014~2024 11개.
- 고동행(상위 20%) 12.6% vs 저동행(하위 20%) −0.8%(차 **+13.4%p**, 중앙 +14.5, 양수 9/11년, t 1.8) / 상위 300 평균 8.0% / 코스피 10.2%. 개발(형성 2014~2020) 차 +12.2%p(양수 6/7, t 1.7), 검증(2021~2024) +15.4%p(양수 3/4, t 0.9) → 사전 합격.
- 연도별 차: 2014 −16.1, 2015 +17.5, 2016 +0.7, 2017 +2.3, 2018 +12.1, 2019 +35.2, 2020 +33.8, 2021 +14.5, 2022 +22.4, 2023 **−31.5**, 2024 +55.9. 2019·2020·2024에 큰 몫.
- 통제(Fama-MacBeth, 연도별 횡단면 12개월 수익 ~ 표준화 상관): 동행성 +4.8%p/1σ(t 2.1, 양수 9/11); +시총 +5.0%p(t 2.1); +직전 12개월 수익 +5.3%p(t 2.2, 8/11) — 시총·직전 수익을 통제해도 유지.
- 해석: 미국 동행성이 높은 종목이 저동행 종목보다 평균 연 13%p 높고, 고동행은 상위 300·코스피 대비 +4.6%p·+2.4%p 정도(초과 크기는 작음) — 차이의 상당 부분은 저동행(내수·국내 요인)이 부진했기 때문. 변동 큼(−31%p~+56%p), t 약 2 수준. 사후 종목 선택 아님(형성 시점 상위 300).

## 신용융자비율 경고 비중 조절 (PREREG_overlay.md sha256 고정 후 overlay.py; 2026-10-27)
- 기초: 고동행 상위20% 반기(B). 신호: 신용융자/예탁금(ECOS 월말), 2개월 지연, 컷 c는 개발 샤프로 선택 → 0.33. 비중 1 / 0.5(경고월 63%), 비용 |Δw|×0.185%.
- 개발: CAGR 11.9→12.4, 샤프 0.55→0.82, MDD −46.6→−26.0. 검증(1회): CAGR 14.0→13.9, 샤프 0.63→0.83, MDD −31.0→−18.6 → 사전 기준(샤프↑·MDD 개선) 합격, CAGR는 동일 수준.
- 1개월 지연이면 검증 CAGR 15.3·샤프 0.91. w=0(경고월 현금)은 검증 샤프 0.91·MDD −18.4, CAGR 13.0.
- 일반성: 상위300 EW 검증 샤프 0.35→0.54·MDD −33.6→−16.7, 코스피 0.40→0.59·−34.8→−19.7 (방향 동일).
- 대조: 같은 평균 비중 고정 시 검증 샤프 0.67·MDD −21.3(규칙 0.83·−18.6). 경고월 무작위 3000회 중 규칙 샤프 이상 5.8%.
- 한계: 컷 민감 — c=0.28~0.30은 검증 CAGR 7~9%로 하락, c≥0.36은 규칙이 거의 작동 안 함(개발 MDD −40%대); 0.33 근방에서만 효과. 사후(2026-01~10-23)는 상승장에서 절반 비중이라 CAGR 80.7→54.5·샤프 1.03→0.77로 불리(9월 비율 0.319<0.33 → 경고 아님이나 2개월 지연으로 7~8월 경고 반영). 낙폭 목적 규칙이며 수익 목적 아님.
