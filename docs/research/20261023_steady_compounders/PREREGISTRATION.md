# 사전등록 — 3년간 큰 하락 없이 꾸준히 오른 종목의 특징 (2026-10-23)

결과를 보기 전에 고정한다. sha256 은 `PREREGISTRATION.sha256`. 고친 내용은 '변경 기록'에만 덧붙인다.

## 질문

1. 3년 동안 큰 하락 없이 꾸준히 오른 종목('꾸준한 상승주', SC)은 얼마나 흔하고, 어떤 회사였나?
   — 같은 만큼 올랐지만 크게 흔들린 종목('거친 승자', RW)과 무엇이 달랐나?
2. 시작 시점에 알 수 있는 특징으로 SC 를 미리 고를 수 있나? 고른 바구니는 지수보다 나은가?

## 대상·자료

- 대상: 시작일 s 의 당시 S&P500 구성 종목(fja05680 명단, 1996~2026-08-18). 시작일 = 분기 마지막 거래일, 2000-03 ~ 2023-06.
- 가격: DataVault raw/yahoo 무수정 + 분할 보정(`<` 분할일) + 배당 재투자(총수익). 현재 상장 종목만 있음 → **생존 편향**. 시작일별 빠진 비율을 함께 보고.
- 티커 이름 변경·재사용은 random_portfolios.py 규칙(RENAME·REUSED)과 거래대금 필터(시작일 60일 달러 거래대금 < 그날 명단 중앙값 10% 이면 다른 회사로 보고 제외).
- 재무: SEC companyfacts(XBRL). **시작일 이전에 제출(filed ≤ s)된 연간(FY, 12개월) 값만** 사용. 업종 = SEC SIC.

## 정의 (창 = s 부터 3년, 마지막 거래일 ≤ s+3년)

- **SC(꾸준한 상승주)**: 총수익 연복리 ≥ 15% **그리고** 창 안 최대낙폭(일별 총수익) ≤ 20% **그리고** log 총수익 vs 시간 직선 적합 R² ≥ 0.80.
- **RW(거친 승자)**: 연복리 ≥ 15% 그리고 최대낙폭 > 30%.
- 민감도: 낙폭 15/25%, 연복리 10/20%.
- 창 끝 전에 가격이 끊긴 종목은 분류에서 빼고 수를 보고.

## 1부 — 설명 (판정 없음, 크기 보고)

- 시작일별 SC·RW 비율(시장 국면별 차이).
- SC vs RW vs 나머지의 **시작 시점** 특징 중앙값: 과거 3년 연복리·낙폭·R²·과거 SC 여부, 1년 변동성, 베타(2년 일별 vs SPY), 12−1개월 모멘텀, 52주 고점 거리, 배당수익률, 시총(2010~), 재무(2010~: 매출 3년 성장률, 최근 4개 회계연도 매출 증가 횟수, 순이익 흑자·증가 횟수, ROE, 매출총이익률, 영업이익률, 부채/자산, 주식 수 3년 변화, E/P·B/P·S/P), 업종.
- **창 동안** 무슨 일이 있었나: 매출 성장, 순이익 성장, 시총 변화 = 매출 성장 + 주가매출비율(P/S) 변화 분해.

## 2부 — 미리 고를 수 있나 (판정)

특징과 가설 방향(+ = 높을수록 SC 가능성 ↑):

| 코드 | 특징 | 방향 |
|---|---|---|
| F1 | 과거 3년 SC 여부(지속성) | + |
| F2 | 과거 3년 R²(매끄러움) | + |
| F3 | 1년 일별 변동성 | − |
| F4 | 베타 | − |
| F5 | 12−1개월 모멘텀 | + |
| F6 | ROE | + |
| F7 | 최근 4개 회계연도 매출 증가 횟수 | + |
| F8 | 최근 4개 회계연도 순이익 흑자·증가 횟수 | + |
| F9 | 배당 지급 여부 | + |
| F10 | 부채/자산 | − |
| (설명만) | E/P, 시총 | 방향 미정 — 결합에서 제외 |

- 측정: 시작일마다 특징 5분위(F1·F9 는 해당/비해당). **상승 배율(lift) = 유리한 분위의 SC 비율 / 그 시작일 전체 SC 비율**, 그리고 유리 분위 − 불리 분위의 앞 3년 연복리 차·낙폭 중앙값 차.
- 구간: **개발 = 시작 2010-03 ~ 2016-12, 확인 = 2017-03 ~ 2023-06** (재무가 2010~ 이라 공통). 가격 특징 F1~F5 는 2000~2009 시작도 설명용으로 보고.
- **특징 판정**: 개발·확인 모두 lift ≥ 1.25 그리고 각 구간 시작연도의 60% 이상에서 lift > 1 → '특징 확인'. 개발만 → '개발만'. 아니면 '아님'.
- **바구니 시험(확인 구간)**: 개발 구간에서 '개발 lift ≥ 1.25·연도 60%' 인 특징만 가설 방향 z점수 평균(결합 점수). 매년 첫 거래일 결합 점수 상위 20종목 동일가중, 1년 보유 후 재조정, 2017-01 ~ 2026-08. 비교: SPY, QQQ, RSP(동일가중 S&P), 같은 명단 무작위 20종목 2,000회 중앙값. 지표 CAGR·변동성·샤프·MDD. 편도 비용 0.1%.
  - **판정: 샤프가 SPY·RSP·무작위 중앙값 모두보다 높고 CAGR ≥ SPY − 1%p → '실전 후보'.** 아니면 '설명용'. (무작위와 바구니는 같은 생존 편향, SPY·RSP 는 편향 없음 — 무작위 대비가 공정 기준.)
  - 개발 구간(2010-01 ~ 2016-12)도 같은 방식으로 보고(표본 내).
