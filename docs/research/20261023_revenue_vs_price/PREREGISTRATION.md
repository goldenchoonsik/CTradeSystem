# 매출과 주가 — 사전 정의 (2026-10-23, 결과를 보기 전에 고정)

질문 (사용자): ① 주가는 매출과 관련이 깊은가 ② 이익은 그대로인데 매출만 커진 경우 ③ 매출 **증가값**이 커질 때 vs 매출 **증가율**이 커질 때.

## 사건 단위
S&P500 구성종목(당시 명단)의 10-K 한 건 = 한 사건. 같은 공시(filed)에 실린 최근 3개 회계연도(R0,R1,R2 / N0,N1,N2)만 사용 → 재작성도 같은 공시 기준, 미래참조 없음.
진입 = 공시일 다음 거래일 종가. 앞으로 12개월(252거래일)·3개월(63) 총수익(배당 재투자). 초과수익 = 종목 − SPY 같은 기간.
회계연도 수익(동시기) = 회계연도 말 직전 1년 총수익(이미 공시 전에 일어난 가격 변화).

## 변수
- 증가율 g0 = R0/R1−1, 직전 증가율 g1 = R1/R2−1
- 증가값 dR0 = R0−R1, dR1 = R1−R2
- **증가값 확대** AMT = (dR0−dR1)/R1  (증가값 자체가 커졌나. 일정한 비율로 크는 회사도 +)
- **증가율 가속** ACC = g0−g1  (증가율 자체가 올랐나)
- 이익 그대로: N0>0,N1>0 이고 |N0/N1−1| ≤ 10%. 이익 증가: N0/N1−1 ≥ 20%.

## 판정 규칙 (고정)
1. 동시기: 회계연도 초과수익과 매출 증가율/이익 증가율의 순위상관(회계연도 말 연도별 계산 후 평균).
2. 이익 그대로 조건에서 매출 증가율 구간별(<0, 0~5, 5~15, 15~30, ≥30%) 회계연도 초과수익(동시기)과 공시 후 12개월 초과수익.
3. 예측력: 공시 분기(달력) 안에서 AMT·ACC·g0 5분위, 상위−하위 5분위의 12개월 수익 차이. t 값은 공시 연도별 평균(연 단위 13~16개)으로 계산. **|t|≥2 이고 이익 그대로 하위집합에서도 같은 부호**여야 '남는다'.
4. 2×2: AMT>0 안에서 ACC 위/아래.
생존 편향: 현재 상장 종목만 가격이 있음(빠진 비율 보고).

## 추가 (같은 날, 결과 보기 전 — 사용자 요청 "매출 커지고 이익 하락")
- 이익 하락: N1>0 이고 N0/N1−1 ≤ −20% (N0>0). 적자 전환(N1>0, N0≤0)은 따로 센다.
- 매출 상승: g0 ≥ 10%. 비교 칸: [매출↑·이익↑(≥+20%)], [매출↑·이익 그대로], [매출↑·이익↓], [매출↑·적자전환], [매출 그대로(|g0|≤5%)·이익↓].
- 보는 것: 회계연도 초과수익(동시기)과 공시 후 12개월 초과수익의 칸별 평균·중앙값·n, 공시 연도별 t.
