# 무작위 N종목 포트폴리오 vs SPY·QQQ (2026-10-21)

> **질문.** 종목을 고르는 실력이 0이면, 미국 개별종목으로 직접 짠 포트폴리오는 지수 ETF와 비교해 어떤 분포가 나오는가?
>
> **결론.** 데이터가 깨끗한 2013~2021년 시작 구간에서, 무작위 5~30종목 포트폴리오가 SPY를 이긴 확률은 **26~35%**(~2026-08 기준 26~31%), QQQ를 이긴 확률은 **3~11%** 였다.
> - 평균은 SPY와 같다. 그런데 중앙값은 SPY보다 연 **1.5~3.2%p 낮다**(~2026-08).
> - 원인은 비용이나 세금이 아니다. 극소수의 초대형 승자(NVDA 2010→2026 521배 등)를 놓치는 것이다. 인덱스 ETF는 그 종목들을 반드시 담는다.
> - 매년 리밸런싱해서 한국 세금(양도세 22%)을 내는 효과는 연 −0.6 ~ +0.2%p로 작다.

## 방법
- **명단:** 당시 S&P500 구성 종목.
  - 출처는 [fja05680/sp500](https://github.com/fja05680/sp500)(MIT)이고, `data_sp500_membership/`에 받아 두었다. 1996~2026-08-18 기간, 날짜별로 그날의 티커가 들어 있다.
  - 이 저장소의 원본 명단은 Clenow 책에서 왔고, 이후 변경분은 위키피디아로 보완했다. 초기 연도 명단은 487~494개라 일부 종목이 빠졌을 수 있다(저장소 README 안내).
- **가격:** `raw/yahoo`(현재 상장 종목만), `us_data.load`(분할 `<` 정정판), 배당 재투자(총수익).
- **시작과 종료:** 시작은 2000~2021년 매년 첫 거래일이다. 종료는 2023-12-29(반도체 급등 제외)와 2026-08-31(포함)이며, 보유 5년 이상인 경우만 집계했다.
- **추첨:** 시작연도마다, N마다 1만 번씩 무작위로 뽑는다(N = 1, 5, 10, 20, 30, 50, 100). 같은 비중으로 사서 보유한다(B&H).
- **상폐·피인수 종목**은 Yahoo에 없어서 두 가지로 처리했다.
  - **E 제외:** 살아남은 종목에서만 뽑는다. 생존 편향 때문에 개별종목에 유리한 **상한**이 된다.
  - **Q 지수대체:** 명단 전체에서 뽑되, 데이터가 없는 종목은 SPY 수익으로 채운다. 분산이 줄어 결과가 지수 쪽으로 끌린다.
- **시작일 기준 빠진 종목 비율:** 2000년 54% → 2010년 33% → 2015년 24% → 2019년 13% → 2021년 9%. 그래서 **2013년 이후 시작 구간을 주 결과로 본다.**
- **티커 변경:** 33건(BK→BNY, ANTM→ELV, MMC→MRSH, FB→META, UTX→RTX 등)을 직접 이어 붙였다.
- **티커 재사용:**
  - T, CB, IR은 날짜 조건으로 막았다.
  - 시작일 60일 달러 거래대금이 그날 명단 중앙값의 10%에 못 미치면 제외했다. 실측 사례: EP(옛 El Paso → 지금은 거래대금 0인 다른 회사), CCU(옛 Clear Channel → 칠레 맥주 ADR), CSR.
  - 이 과정에서 2000년대 초 거래가 적던 실제 구성 종목도 해마다 몇 개씩 함께 빠졌다.
- **R (재조정 + 세금):** 같은 N종목을 매년 초 같은 비중으로 다시 맞춘다.
  - 비용은 편도 0.1%다.
  - 원화 기준 실현이익에서 연 250만 원을 공제하고 22%를 다음 해 초에 낸다. 배당은 15% 원천징수한다.
  - 마지막 날 전량 청산해 정산한다. 시작 금액은 원화 1억 원이다.

## 해석
1. **실력 없이 직접 짠 포트폴리오의 '흔한 결과'는 SPY 미달이다.**
   - 최근 구간 기준으로 5~30종목이면 약 70%의 확률로 SPY에, 약 90%의 확률로 QQQ에 진다.
   - 평균은 SPY와 같고 중앙값만 낮다. 즉 비용이나 세금 문제가 아니라 수익 분포의 왜도 문제다.
2. **종목 수를 늘려도 격차가 천천히만 줄어든다.**
   - 중앙값 − 평균은 1종목 −4.8, 10종목 −2.6, 30종목 −1.6, 100종목 −0.9%p다(2013~ → 2026-08).
   - 초대형 승자 몇 개가 지수 수익의 상당 부분을 만든 시대라, 100종목을 뽑아도 그 종목들이 빠질 확률이 높다.
3. **비용·세금 차이는 2차적이다.** 보수 차이는 연 0~0.2%p, 연 1회 재조정의 세금 효과는 연 −0.6~+0.2%p다.
4. **이 시험은 개별종목에 유리하게 기울어 있다.** 생존 편향이 있고 무작위 추출이다. 실제 개인 투자자는 여기에 잦은 매매와 늦은 손절 같은 행동 비용까지 더해진다(Barber & Odean 2000).
5. **비교판 결과와도 맞는다.** 시가총액 상위 50·100종목(XLG·OEF)은 SPY와 같았고, 2012년 말 상위 10종목 보유는 QQQ에 못 미쳤다([../20261021_strategy_board/README.md](../20261021_strategy_board/README.md), [../20261021_slot_swing_recompute/README.md](../20261021_slot_swing_recompute/README.md)).

## 한계
- 생존 편향이 있다. 상폐·피인수 종목은 Yahoo에 없다. E는 상한이고, Q는 그 종목을 지수 수익으로 채운 근사다.
- 티커 재사용 중에서 거래대금이 큰 다른 회사가 같은 티커를 쓰는 경우는 걸러내지 못했을 수 있다.
- 무작위 추출은 같은 비중이다. 시가총액 비중으로 상위 종목을 고르는 방식은 비교판의 XLG·OEF 결과를 참고한다.
- 보유(B&H) 비교에는 진입 비용 0.1%만 넣었다. 한국 세금은 마지막 날 22%로 정산되므로 승패 순서가 바뀌지 않는다. 그래서 결과 1·2의 확률은 세전과 세후가 같다.
