# 단타 종결 프로그램 C — 매도세 없는 구조적 틈새 재검증 (사전 등록, 2026-10-11)

목적: 이미 비용을 넘은 것으로 보였던 틈새(C1~C3)를 **실행 조건**으로 다시 판정하고, 소형주 연구에서 나온 단서(C4)와
선물 신패턴(C5)을 **발견에 쓰지 않은 기간**에서 검증한다. 판정 전 정의·비용·기준을 고정한다.

## 데이터
- K200 선물 연속(10100) 1분봉 종가·거래량, 2016-06-20 ~ 2026-10-08 (`DataVault/normalized/macro/10100_1m.parquet`, 시가 없음 → 체결은 해당 분 종가)
- 069500·122630 1분봉 OHLC, 2024-07/08 ~ 2026-10-08 (`DataVault/normalized/candles_1m/`)

## 공통
- 제외일: 선물 마지막 봉이 15:45 가 아닌 날(만기일 15:15·특수 거래일 16:45)과 그 **다음 거래일**(연속월물 교체 점프)
- 하루 1회 이하 거래 → t = 거래 수익 시계열의 평균/표준오차
- 선물 비용(왕복): 진입·청산 각 1틱(0.05pt) + 수수료 0.003% → `0.1 / 가격 + 0.006%` (가격 1,000pt 에서 약 0.016%)
- ETF 비용(왕복): 진입 1틱(5원) + 수수료 0.015%×2 (동시호가 청산은 스프레드 없음) → `5 / 가격 + 0.03%`
- 세금: 선물 양도세(11%, 연 250만원 공제)·122630 보유기간과세는 판정에 넣지 않고 결과에 따로 적는다

## 판정 (모두 충족 = 합격)
1. 비용 후 거래당 평균 > 0, t > 3
2. 연도별 양수 비율 ≥ 2/3 (거래 10건 미만 연도 제외)
3. 최근 12개월(2025-10 ~ 2026-10) 비용 후 합 > 0
4. 아래 각 항목의 **검증 구간** 단독으로도 1·2 충족 (검증 구간 = 그 규칙을 찾을 때 쓰지 않은 기간)
