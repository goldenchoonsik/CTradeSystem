# 삼성전자 단일 종목 다각도 연구 (2026-10-22)

질문: 금리·환율·메모리 단가·재고 사이클·수출·SOX·마이크론·외국인·실적·재무·지분(자사주) 중 무엇이 삼성 주가와 관련 있고, 무엇이 **미리** 알려 주나.
사전등록: `PREREGISTRATION.md` (sha256 원본 ee68dfff…, 결과 전 데이터 보충 2회 → `PREREGISTRATION.sha256`).

## 1. 확인된 것 (크기 먼저)

**(1) 주가가 메모리 데이터보다 먼저 움직인다 — 모든 기간 일관**
- 삼성 고점·저점 16회(1994~2025, −25% 이상 국면) 대비 전환 시점: D램 수출물가 전년비는 **중앙 5개월 늦게** 꺾임(먼저 꺾인 것 3/15), 메모리 수출 0/8, 마이크론 매출총이익률 0/4 — 공개 메모리 지표는 주가 뒤를 따라감. SOX 는 같은 달(0).
- 그래서 '메모리 단가 가속'으로 사면 오히려 늦음: 2000~2016 D램 가속 상위 1/3 의 이후 6개월이 하위 1/3 보다 **−14%p**(t −2.6), 마이크론 이익률 개선도 −12%p(t −3.6). 2017~ 은 +5%p 로 뒤집혀 방향조차 불안정 → 타이밍 용도 버림.

**(2) 미 10년물 금리 6개월 변화 — 사전등록 13개 중 유일한 '실전 후보'**
- 금리 1표준편차(0.58%p) 상승당 이후 6개월 삼성 수익 −5.2%p(개발 2000~16, t −2.7) / −6.0%p(확인 2017~26, t −2.0).
- 3분위: 금리 하락 구간 이후 6개월 +10.7% / +16.9%, 금리 상승 구간 +0.6% / +2.7% (개발 / 확인).
- 한 해씩 빼도 부호 유지 17/17, 10/10. 코스피 대비 초과에서도 음(−3.0 / −2.5%p). SOX(달러)도 같은 방향(−4.1 / −3.3%p), S&P500 은 0 → **반도체·성장주 할인율 효과**.
- 하지만 겹치지 않는 표본만 쓰면 t −0.8~−2.0 (확인 −1.8~+0.1) — 독립 표본이 20~33개뿐이라 크기는 불확실.
- 비중 규칙으로 쓰면: 사전등록 합성 규칙(미·한 금리) 확인 구간 노출 맞춤 대비 **+0.0%p, MDD −41% vs 보유 −38%** → 버림. H7 단독(참고)은 +2.1%p/년이지만 MDD −44% vs −31%(비중 1.75배까지 올리는 구조 탓).

**(3) 같이 움직이는 몫 (예측 아님)**
- 삼성 월 수익률 분산 중 SOX 설명 ~30%(2015~ 37%, 마이크론 단독 40%), 원/달러 0~4%, 코스피 58%(삼성이 지수 자체). SOX β 0.5~0.8. 미 10년물 1%p 상승 → 같은 달 −2.7%(2015~).
- 5년 이동창 SOX 설명력 0.10(2015)~0.51(2005), 2022~23 0.4 안팎.

**(4) 사건 — 전부 당일 반영**
- 잠정실적(51회, 2014~): 당일 |수익| 1.72% vs 평상시 1.44%(정보가 이미 대부분 반영), 이후 20일 코스피 대비 +0.01%. 영업이익 전년비 감소 분기(12회)가 이후 20일 +4.2% vs 증가 분기 +1.2% — 바닥 근처 나쁜 실적(주가 선행과 같은 이야기).
- 마이크론 실적(90회, 2004~): 삼성 다음 거래일 반응과 상관 +0.25, 이후 20일과 +0.01 → 하루에 끝남. 마이크론 +5% 이상 24회 vs −5% 이하 23회의 삼성 이후 20일 차이 +1.9%p(검정 안 함, 작음).
- 자사주 취득결정 14회: 이후 20일 코스피 대비 +1.6% 평균, 2015~17 소각 프로그램은 120일 −7~+34%, 2025~26 은 메모리 급등과 겹침(인과 구분 불가).

**(5) 효과 없음(크기로)**
- 외국인 보유율 60개월 백분위: 개발 −0.5%p, 확인 −5.1%p(t −0.9) — 있어도 6개월 5%p 이하.
- 원/달러 1년 고점 대비 거리: 개발 −0.2%p, 확인 −4.5%p(t −0.8). 10-16 낙폭 국면 관찰(15중 11)은 무조건 월 검정에선 재현 안 됨.
- 삼성 vs SOX 상대 부진 되돌림: 개발 +1.1%p → 확인 **−11.9%p(t −2.1)**, 2017~ 은 뒤처지면 더 뒤처짐(되돌림 아닌 지속).
- 우선주 할인율 z → 우선주−보통주: ±0.5%p, 갈아타기 엣지 없음(배당 제외라 우선주에 불리한 쪽 편향 있음).
- 반도체 출하−재고 갭 '수준': 개발 −5.9%p(반대), 확인 +8.5%p — 불안정.
