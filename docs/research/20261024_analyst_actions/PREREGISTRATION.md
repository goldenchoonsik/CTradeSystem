# 애널리스트 등급·목표주가 변경과 주가 (2026-10-24, 결과 보기 전 고정)

질문: 애널리스트 전망(등급·목표주가)이 바뀌면 주가가 그 뒤에도 따라가는가, 목표주가가 현재가보다 높은 종목이 더 오르는가.
데이터: Yahoo upgrades_downgrades (yfinance) 종목별 원본, 2012-09~2026-10. 종목 = 앞선 매출 연구 사건 패널의 581종목(현재 상장 → 생존 편향).
시각 대응이 불확실하므로(타임존 불명) 변경일 d 에 대해 **즉시 반응 = 종가(d−1)→종가(d+1)**, **이후 표류 = 종가(d+1)→+20·+60 거래일**만 신호로 본다. 초과수익 = 종목 − SPY 같은 기간.
같은 종목·같은 날 여러 증권사 변경은 한 건으로 합친다(부호 = 다수결, 동수면 제외).

## 시험
- **R 등급**: Action 이 up / down 인 건(init 제외). 표류 +20·+60일 초과수익, up − down 차이.
- **P 목표가**: priceTargetAction 이 Raises / Lowers 이고 이전·현재 목표가가 모두 >0. 변경률 = 현재/이전−1. Raises − Lowers 차이, 변경률 크기 구간(<−10, −10~0, 0~10, 10~20, ≥20%).
- **U 목표 상승여력**: 각 종목·월말에 직전 90일 안의 목표가 중앙값 / 월말 종가 − 1 (목표가 3건 이상인 종목만). 같은 달 안 5분위 → 다음 달 초과수익, 상−하.
- **B 수정 폭**: 종목·월 단위로 직전 30일 (Raises − Lowers)/(Raises+Lowers) (5건 이상). 같은 달 5분위 → 다음 달 초과수익, 상−하.

## 판정
t 는 사건 연도별(R,P) 또는 월(U,B → 연도 평균 t) 평균으로 계산. **|t|≥2 이고 2012~2019·2020~ 두 반쪽 모두 같은 부호**일 때만 '표류가 있다'.
즉시 반응은 따로 보고(이미 가격에 반영된 몫). 거래비용은 반영하지 않으므로 합격해도 크기는 비용 전 숫자.
