# '큰 승자 잡기' 전략의 실제 ETF 성적 (2026-10-21)

> **결론: 승자를 '미리' 고르는 계열 중에 QQQ를 이긴 실제 운용 ETF는 없다.**
> - 모멘텀(SPMO)만 SPY를 이겼는데, 그 몫은 거의 2024년 이후 구간이다.
> - CANSLIM(FFTY), 신규상장(IPO·FPX), 소형 성장(IWO)은 SPY에도 못 미쳤다.
> - 혁신 성장(ARKK)은 SPY를 조금 넘었지만 낙폭이 −75%였다.

## 조건
- **비교 잣대:** 비교판 `etf_scan.py`와 같다.
  - 원화 1억으로 시작해 매수 후 보유한다. 비용은 편도 0.1%, 배당은 재투자한다.
  - 세후는 미국 직투 22%에 배당 15% 원천징수를 적용한다.
- **ETF 고르는 법:** 전략별 대표 ETF를 미리 정했다. 수익률을 보고 고른 것이 아니다.
- **주의:** 지금 살아 있는 유명 ETF만 들어갔다. 같은 계열에서 사라진 ETF는 빠져 있으므로 결과는 실제보다 좋게 나온 쪽이다.
