# MULTI-ASSET QUANT MASTER ENGINE v6.6 (Modular)

분 및 초 단위 아카이브 데이터와 수급 피처를 활용하는 대용량 다중 자산(원화 마켓 전체 코인) 이원화 퀀트 엔진입니다.

---

## 🚀 실행 및 운용 가이드

### ① 가동 환경 실행
*   **웹 대시보드 기동 (FastAPI + WebSocket)**:
    ```bash
    ./scripts/run_web.sh
    # 또는 프로젝트 루트에서:
    ./scripts/run_baker.sh
    ```
    > [!IMPORTANT]
    > **리눅스 환경 실행 주의**: 리눅스/맥 환경에서는 백슬래시(`\`)가 이스케이프 문자나 특수 기호로 처리될 수 있으므로, 실행 경로 입력 시 반드시 슬래시(`/`)를 사용해야 합니다. (예: `python web_dashboard/main.py` 로 실행)

### ② 타겟 코인 변경 & 디렉토리 자동 격리
*   GUI 상단의 **`🪙 타겟 코인 선택` 드롭다운(Combobox)**을 클릭하여 실시간으로 원하는 코인을 선택합니다.
*   선택 즉시 내부 타겟 설정이 동적으로 변환되며, 결과물은 **`data/{SYMBOL}/`** 하위 디렉토리에 저장됩니다. (실제 저장 시점에만 폴더가 생성됩니다.)
*   **세션 유지**: 마지막으로 선택한 타겟 코인 및 사용자가 입력한 모든 날짜 설정(3구간 범위 및 아카이브 수집 범위)은 `config.json`에 저장되어 프로그램 재기동 시 자동으로 완벽 복원됩니다.

### ③ 데이터 파이프라인 빌드 공정 (아카이브 센터 3단계 수집)
1. GUI 우측 하단의 **`📂 업비트 아카이브 센터`** 버튼 클릭
2. 시작 년월 ~ 종료 년월 범위(`YYYY-MM`, 기본 시작값 `2025-01`) 입력 및 **`시간 단위` 드롭다운(Combobox)** 설정 (1s, 1m, 3m, 5m, 10m, 15m, 30m, 60m 지원)
3. **`📥 1. 업비트 다운로드 (캔들+체결)`** 실행 ➡️ 지정 기간 내 업비트 캔들과 체결 데이터를 로컬에 일괄 수집 (네트워크 에러 발생 시 3회 자동 재시도)
4. **`📥 2. 바이낸스 다운로드`** 실행 ➡️ 지정 기간 내 바이낸스 `1m` 분봉 원본 데이터를 다운로드하여 로컬에 수집 (네트워크 에러 발생 시 3회 자동 재시도)
5. **`⚙️ 3. 통합 데이터셋 빌드`** 클릭 ➡️ KST 시간대 정렬 및 무결성 검증을 거쳐 `data/{SYMBOL}/data_snapshot_{interval}.csv` 초고속 완공 (최근 파일이 누락되는 경우, 데이터가 모두 존재하는 일자까지만 자동 슬라이싱하여 안정적으로 최종 결합을 완공합니다.)

### ④ 3구간(학습 - 최적화 - 테스트) 시계열 통제 및 훈련
*   **`🧠 1. 학습 구간`**: AI 모델이 기본 학습(Study) 패턴을 습득하는 훈련 데이터셋 범위
*   **`🔍 2. 최적화 구간`**: 학습된 AI 모델의 예측을 기반으로 Optuna가 수수료/슬리피지 극복 하이퍼파라미터 조합을 탐색 및 검증하는 튜닝 데이터셋 범위
*   **`📊 3. 테스트 구간`**: 모델이 학습 및 튜닝 시점에 단 한 번도 보지 못한 완전 격리된 미래 시계열에서 실전 시뮬레이션을 수행하는 백테스트 데이터셋 범위
*   **`🧠 [2] v6.6 3구간 최적화 & 빌드`**: 1번 구간 학습 ➡️ 2번 구간 Optuna 튜닝 ➡️ 최종 통합 마스터 모델 저장 과정 수행 (옵션 선택 시 학습 완료 후 기존 이름에 `_V00`, `_V01`, `_V02`... 접미사를 붙여 신규 프로젝트를 자동으로 생성 및 복제합니다.)
*   **`📊 [3] 격리구간 백테스트`**: 3번 구간 격리 파일들을 타겟팅하여 최종 시뮬레이션 백테스트 결과 리포트 출력

## 📂 프로젝트 핵심 구조

| 파일/디렉토리 | 유형 | 설명 |
| :--- | :--- | :--- |
| `web_dashboard/` | 디렉토리 | FastAPI 기반 반응형 웹 대시보드 컴포넌트 (Controller - Web) |
| `core/data_manager.py` | Python 파일 | **[Data]** 역사적 아카이브 다운로드, 스마트 로컬 캐싱 및 KST 시계열 통합 빌더 |
| `core/model_engine.py` | Python 파일 | **[AI Engine]** 피처 엔지니어링 수행, Optuna 하이퍼파라미터 튜닝 및 전수 마스터 모델 학습 |
| `core/backtester.py` | Python 파일 | **[Backtester]** 격리된 미래 테스트 데이터셋 기반 시뮬레이터 및 성과 평가 |
| `../docs/STRATEGY.md` | 마크다운 | 11대 피처 정의, 레이블링 규칙 및 모델 명세 (프로젝트 공통 통합 문서) |
| `../docs/ARCHITECTURE.md` | 마크다운 | 데이터 아키텍처 및 무결성 규칙 명세 (프로젝트 공통 통합 문서) |
| `data/{SYMBOL}/` | 디렉토리 | **[자산 격리 폴더]** 각 코인별 데이터 스냅샷, 최적 파라미터, 모델 파일 저장소 |
